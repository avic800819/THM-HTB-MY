==================================================
【網路基礎】Linux / 靶機常見服務與存取方式對照表
==================================================

1. Web 服務 (HTTP / HTTPS)
   - 常用 Port：80, 443, 8080, 8000, 3000, 或隨機高位 Port (如 41885)
   - 存取工具：Chrome / Edge / Firefox 瀏覽器
   - 存取格式：http://<IP>:<Port> 或 https://<IP>:<Port>[cite: 27]

2. Linux 文字終端連線 (SSH)
   - 常用 Port：22, 2222
   - 存取工具：PowerShell, CMD, Terminal, PuTTY
   - 存取指令：ssh <username>@<IP> -p <Port>
   - 錯誤示範：不可在瀏覽器輸入 http://<IP>:22 (協定不符無法開啟)

3. Windows 圖形桌面 (RDP)
   - 常用 Port：3389
   - 存取工具：Windows 內建「遠端桌面連線」(mstsc)[cite: 27]
   - 存取格式：<IP>:<Port>[cite: 27]
